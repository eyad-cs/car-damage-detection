
- ملف CSS مرتب إلى أقسام مشروحة؛ `display: flex` يرتب العناصر بجانب بعض، و`@media` يغير بعض الأحجام والترتيب على الجوال.
- بقي `meta charset="UTF-8"` لأن حذف ترميز العربية قد يجعلها تظهر كرموز في بعض طرق فتح الملف. نجاحها عندك بدونه لا يضمن ذلك في كل الحالات.
- بقي `meta viewport` حتى يظهر تصميم الجوال بالحجم الصحيح.
- بقيت الخطوط والألوان والمقاسات اللازمة للمحافظة على التصميم، وترخيص الخط، والتحقق الأساسي من المدخلات والروابط.
