# بصيرة

## التشغيل
فك الضغط في مجلد جديد، أغلق التشغيل القديم، ثم شغّل `run_site.bat`.
افتح http://127.0.0.1:8000 واترك نافذة التشغيل مفتوحة.
الموقع يحتاج Python؛ GitHub Pages وحده لا يشغّل البحث.

## التعديلات
- بطاقات eBay وAliExpress، مع فلتر «الكل / eBay / AliExpress» يعمل بـ HTML وCSS فقط.
- فلتر متجر لا يحتوي على نتائج يكون معطلًا، وعند بحث جديد يبدأ العرض على «الكل».
- `isBestPick` يضيف إطارًا وخلفية خضراء؛ نص الشارة يأتي من `badge`.
- ترتيب `items` يبقى كما أرسلته الخدمة، حتى عند استخدام فلتر المتجر.
- الشحن صفر: «شحن مجاني». الشحن غير المحدد: «يُحدد في صفحة المنتج».
- تصنيف القطعة وحالتها للعرض داخل البطاقة. فلتر الحالة أزيل من الطلب.
- رقم الهيكل اختياري. الشركات الست وثلاثة طرازات لكل شركة كما كانت.

## الملفات الأساسية
| الملف | وظيفته |
| --- | --- |
| `app.py` | فتح الصفحات، إرسال البحث وعرض نتيجته |
| `cars.py` و`models.html` | الشركات والطرازات المحددة |
| `index.html` و`report.html` | الفحص ونتيجته في الصفحة نفسها |
| `parts.html` و`products.html` | نموذج البحث وبطاقات المنتجات |
| `about.html` | نبذة المشروع |
| `chat.html` | واجهة الشات فقط؛ الإرسال معطل حتى يربطه المسؤول عنه |
| `assets/css` | تنسيقات مقسمة بحسب صفحات الموقع |
| `assets/vendor/htmx.min.js` | المكتبة الموجودة لإرسال البحث وتحديث الطرازات |

## الربط
طلب القطع يحتوي: `vin`, `make`, `model`, `year`, `partName`, `partType`.
لا يُرسل `condition`، حتى لو أُضيف يدويًا إلى الطلب.
قيم فلتر نوع القطعة في الطلب بقيت وفق الاتفاق: `original`, `aftermarket`, `any`.
أما `OEM`, `AFTERMARKET`, `UPGRADE_MODIFIED` فهي تصنيفات النتائج المعروضة في البطاقات.
روابط المنتجات والصور يمكن أن تكون عادية أو منسوخة بصيغة Markdown مثل المثال المرسل.

حُذف `chat.py` و`chat-reply.html` و`assets/chat.js` ومسار `/search/chat` والرابط القديم لخدمة الشات.
مسؤول الشات يضيف ربطه إلى `chat.html`؛ لا توجد أسئلة أو ردود محادثة مبرمجة في Python الآن.
تحليل الصور ما زال ينتظر رابط النموذج، والنتيجة مكانها تحت الصورة.
حُذفت سبع صور غير مستخدمة وقواعد CSS القديمة؛ بقيت الخطوط والمكتبة وملفات تراخيصها اللازمة.
